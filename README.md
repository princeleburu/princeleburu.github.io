# Prince Leburu’s academic portfolio

Live website: https://princeleburu.github.io

A lightweight static website, hosted with GitHub Pages. No build tools are required.

## Updating the site

Edit the relevant HTML file: `index.html` for biography, `research.html` for publications, `teaching.html` for teaching and mentorship, `impact.html` for public engagement, or `cv.html` for the web CV.

The shared design is in `assets/styles.css`. Replace `downloads/prince-leburu-cv.pdf` to update the downloadable public CV. Review PDFs for personal or third-party information before publishing.

Commit changes to `main`; GitHub Pages publishes from the repository root. Keep `.nojekyll` in place. Update all five navigation bars if adding a page, and add its URL to `sitemap.xml`.

Keep publication statuses and dates accurate. Only publish approved updates.
